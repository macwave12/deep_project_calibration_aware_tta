# T11 — Independent review loop

Status: open · Owner: three fresh reviewer agents · Depends on: T10

- Technical reviewer: every number traces to a CSV; every claim has evidence; math correct;
  protocols and selection history disclosed.
- "Professor" reviewer: background clarity, fairness, positioning, rigor, likely questions.
- Visual reviewer: renders every slide; legibility, density, consistency.
Each returns blocking / non-blocking findings. Fix → re-render → re-review, ≤3 rounds.
Lead signs off, then Idan.
